# Third-party component

The Windows portable distribution contains the **unmodified, standalone** official
SumatraPDF 3.6.1 x64 portable executable, renamed to `SumatraPDF.exe`.
The application invokes this separate program via documented command-line arguments.

- Project: https://www.sumatrapdfreader.org/
- Binary: https://www.sumatrapdfreader.org/dl/rel/3.6.1/SumatraPDF-3.6.1-64.zip
- License: GPLv3, reproduced as `SumatraPDF-COPYING` in the portable package.
- Exact source tag: `3.6.1rel`, commit `16c59fde8b824ab54c56f23aef910a6fdd874ad0`.
- Corresponding source archive is hosted alongside the binary in this application's
  same GitHub Release as `SumatraPDF-3.6.1-source.zip` (including upstream license,
  third-party sources, and build instructions).
- Upstream source: https://github.com/sumatrapdfreader/sumatrapdf/tree/3.6.1rel

Folder PDF Printer itself is MIT licensed. The SumatraPDF component and its
dependencies retain their upstream licenses. No modifications to SumatraPDF were made.
